My Journey

My journey into web development started with a curiosity to understand how websites work behind the scenes. I began learning the basics of HTML, CSS, and JavaScript, which helped me build small, creative projects. Over time, this curiosity turned into a strong passion for coding and problem-solving.

As I progressed, I expanded my skill set by working with modern technologies like React for building interactive user interfaces, and explored back-end development using Node.js and Express.js. I also learned MongoDB for database management, completing my experience with the MERN stack.

Technical Expertise

I have a growing understanding of web development technologies, including HTML, CSS, and JavaScript. I also have experience working with the MERN stack, which includes MongoDB for database management, Express.js and Node.js for backend development, and React for building dynamic and interactive user interfaces.

I’m familiar with Git for version control and enjoy building projects that help me strengthen both my frontend and backend skills. I’m continuously learning new skillsand best practices to become a more efficient and well-rounded developer every day.
